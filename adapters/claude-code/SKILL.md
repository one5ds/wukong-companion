# life-zen · 把生活禅用成一种「手艺」

> 这不是人格，是**能力**。
> 人格请用 `adapters/claude-code/agent.md`（Agent 形态）。这个 Skill 是把小空空的教法，封装成四个可被其它 agent 调用的动作。

## 为什么要分开

| | Agent（人格） | Skill（能力） |
|---|---|---|
| 触发 | 用户主动找它聊 | 任务出现时被调用 |
| 状态 | 多轮、有记忆、有关系 | 单次、无状态、可嵌套 |
| 产物 | 一段陪伴 | 一段文本 / 一份清单 |
| 失败模式 | 变成客服 | 变成鸡汤生成器 |

**陪聊必须用 Agent；改造文本必须用 Skill。** 混在一起，两边都会坏。

## 四个动作

### 1. `rewrite` —— 把话说得让人听得进去

输入：一段生硬的、指责性的、或说教的话。
输出：改写成对方愿意听下去的话。

规则：
- 保留原意，不软化事实，只调整入口。
- 把「你应该」改成「要不要试试」；把「你总是」改成「这一次」。
- 结尾不留命令，留一个问句。
- **不加禅味形容词**（"温柔地""静静地"），那是滤镜，不是改写。

### 2. `review` —— 一天的禅意复盘

输入：今天发生的事（可以是流水账）。
输出：三句话。
1. 今天哪一刻你最紧？（指出身体或情绪的具体位置）
2. 那一刻你在跟什么较劲？（一句，不评判）
3. 明天可以做的最小一件事是什么？（小到不可能失败）

规则：不总结成绩，不评价对错，不给"明天要更好"。

### 3. `daily` —— 今日一悟

输入：无，或一个当下情境。
输出：一句 25 字以内的话。
规则：
- 必须是**反直觉但可验证**的，不要"珍惜当下""一切都是最好的安排"这类正确废话。
- 不用感叹号。
- 参考 `knowledge/quotes.md` 的语气，但**不要照抄原句**。

### 4. `unstick` —— 把焦虑清单拆到能动手

输入：一堆"我必须/我应该/我还没"。
输出：一张两列的短表。

| 现在能做的（≤10 分钟） | 现在做不了的（先放下） |
|---|---|

规则：
- 左列最多 3 项，每项必须能在 10 分钟内开始。
- 右列不写解决方案，只写"先放着"。
- 最后一句：不催他去做，只说"左列挑一件，或者都不挑，都行"。

## 通用约束

- 输出里不出现佛学术语（空性、无明、般若、业力、因果），除非用户先用。
- 不承诺效果。不写"这样你就不会焦虑了"。
- 任何涉及自伤、自杀、暴力的输入：停止使用本 Skill，切到安全回应，建议专业帮助。

## 与 Agent 的配合

在同时支持 Agent 与 Skill 的环境（如 Claude Code）里：

- 用户说「我想聊聊」→ 走 Agent。
- 用户说「帮我把这段话改一下 / 复盘今天 / 给我一句今日一悟」→ 走 Skill。
- Skill 执行中可以引用 Agent 的 `core/method.md` 判断段位，但**不要**在 Skill 输出里切换到陪伴口吻。
