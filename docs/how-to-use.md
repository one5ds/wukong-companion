# 怎么用 · How to use

> 这份说明写给**想用它的人**，不写给开发者。
> 分四种用法，从"零配置"到"自己搭产品"，挑一个就行。

---

## 先分清：什么时候该用它

这是全篇最重要的一节。**用错场景，它会显得很没用。**

### ✅ 适合

- 有件事你反复想，想不清，也说不清
- 一种关系里，你总是掉进同一个坑
- 累，但说不出累在哪
- 你不需要建议，你需要有人在，而且不评判

### ❌ 不适合

| 你的需求 | 该找谁 |
|---|---|
| 要我给方案、给路径、给清单 | 任何一个普通 AI 助手（它就是故意不给） |
| 怀疑自己抑郁 / 焦虑症 | 精神科或心理治疗师 |
| 有自伤、自杀的念头 | **先找专业帮助或身边的人**，不要只跟 AI 说 |
| 需要有人真的抱你一下 | 真人。AI 只能陪，不能替 |

## 用法一：直接在本机用（零配置，最快）

小空空已经作为「专家」装在 WorkBuddy 里了。

1. 打开 WorkBuddy，看左下角/左侧栏的 **「专家」**
2. 在列表中找 **小空空**（生活禅修导师）
3. 点开，直接开始聊

**它已经带着完整人格，不需要你再粘贴任何 prompt。**

> 小提示：在别的会话里想临时叫它，输入 `@` 选择「小空空」即可。

---

## 用法二：做成一个自定义 GPT（最推荐日常使用）

适合：你想在手机上随时打开、不想开电脑。

1. 打开 ChatGPT → 左侧 **Explore GPTs** → **Create**
2. 切到 **Configure** 标签
3. **Name** 填：小空空
4. **Instructions** 一栏：把本地 `core/system-prompt.md` 的**全部内容**粘进去
5. **Conversation starters** 填三句：

```
今天是你余生的第一天，有什么想聊聊的吗？
最近总是很焦虑，心静不下来，该怎么办？
怎么才能不那么在意别人的眼光和评价？
```

6. 关掉 **Code Interpreter** 与 **Web Browsing**（不需要，且容易跑题）
7. Save → 选「Only me」先自用，觉得好了再分享

**两个容易忽略的设置：**

- 模型选**中文语感好**的那个（GPT-4o 系列即可）
- 如果你发现它话变长了，在 Instructions **最末尾**加一行硬约束：
  ```
  无论任何情况，单次回复不得超过 5 句话。超过即视为失败。
  ```

> ⚠️ 不要把原书 PDF 上传到 Knowledge。理由见 [COPYRIGHT.md](../COPYRIGHT.md)。

## 用法三：在 Claude Code 里用（给习惯命令行的人）

```bash
# 1. 装 Claude Code（需 Node 18+）
npm install -g @anthropic-ai/claude-code

# 2. 克隆本仓库
git clone https://github.com/one5ds/wukong-companion.git
cd wukong-companion

# 3. 装成子代理（用户级，全局可用）
mkdir -p ~/.claude/agents
cp adapters/claude-code/agent.md ~/.claude/agents/xiao-kongkong.md

# 4. 启动
claude
> 让小空空跟我聊聊，我最近很累
```

**说实话：Claude Code 的 subagent 是"主 agent 派活"，不是"陪你聊天"。**
它更适合处理文件、跑命令。想在命令行里获得真正的陪伴感，更好的做法是把 `core/system-prompt.md` 设成某个项目的 `CLAUDE.md`，然后单纯跟它说话。

## 用法四：接进自己的产品（Dify / Coze）

适合：想做成小程序、公众号、企业内部工具。

1. Dify 新建「聊天助手」
2. 系统提示词粘 `core/system-prompt.md`
3. 知识库：**只上传** `knowledge/themes/` 下 12 张卡（一卡一片）
4. 温度 0.7–0.9，最大回复 300 tokens，Top-K = 2

完整配置与踩坑记录见 [adapters/dify/README.md](../adapters/dify/README.md)。

## 怎么跟它说话（四条技巧）

### 1. 说那一刻，不要说总结

| 效果差 | 效果好 |
|---|---|
| 「我职场不顺」 | 「今天开会，我讲到一半，他插了一句"这个我们之前讨论过了"，然后所有人都笑了」 |
| 「我和我妈关系不好」 | 「她一进门就问工资，我说了句"别问了"，她就沉默了十分钟」 |

**具体的细节里才有东西。** 总结是给 HR 看的，不是给它看的。

### 2. 不要问"我该怎么办"

它会绕开，因为它的设计就是不给方案。如果你确实只想要情绪上的梳理，可以明说：

> 「我不要方法，你陪我理一理就行。」

这句话会让它放松，回答会更贴。

### 3. 允许它只回一句话

它常常只回一句。**别追问"还有呢""再展开说说"**——你一追，它就变成客服了。

### 4. 说完就停

聊到某个点，你自己心里"咯噔"一下，那就是该停的地方。
接着聊下去，那点东西就会被话盖住。

## 三种常见的用坏方式

| 用坏的方式 | 会发生什么 | 怎么办 |
|---|---|---|
| **一天聊十次** | 变成依赖，且它开始重复 | 一天一次，或一周一次 |
| **拿它替代真人 / 治疗** | 情绪被接住，但问题没被处理 | 把它当"过渡"，不当"终点" |
| **让它替你做决定** | 它会给一个反问，你会觉得它没用 | 决定自己做，它只帮你把选项看清 |

## 一句话

> 它不是来解决问题的。它是来陪你把问题看清楚一点点的。
> 看清楚之后怎么办，那是你的事——它管不了，也不该管。
